# Business Requirements

## Objective

Build a healthcare analytics platform that enables business users to monitor hospital operations.

## Functional Requirements

- Generate synthetic healthcare data.
- Store data in MySQL.
- Provide SQL reports.
- Build interactive Power BI dashboards.
- Support filtering by department, doctor, patient, city, diagnosis, and insurance.

## Non-Functional Requirements

- Modular Python code.
- Normalized database.
- Easy deployment.
- Maintainable SQL scripts.
- Documented architecture.
