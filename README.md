# Healthcare Data Analytics Pipeline

## Overview

This project demonstrates an end-to-end healthcare analytics pipeline using Python, MySQL, and Power BI. It simulates a hospital environment where patient, admission, billing, and laboratory data are generated, cleaned, stored, analyzed, and visualized to produce business insights.

---

## Objectives

- Generate realistic synthetic healthcare data.
- Clean and validate raw datasets.
- Design and implement a normalized MySQL database.
- Perform SQL-based business analysis.
- Build interactive Power BI dashboards.
- Document the complete analytics workflow.
